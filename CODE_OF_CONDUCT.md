# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep feedback about the work, and make room for
people who are new. Harassment of any kind isn't welcome here.

Report problems to the maintainer privately through
[GitHub security advisories](https://github.com/arjunpundeer7/diorama/security/advisories/new)
or by contacting [@arjunpundeer7](https://github.com/arjunpundeer7). Reports are handled
confidentially.
