# Changelog

## 0.1.0

First release.

- Themes: Honu Lagoon (ASCII), Night Orbit (braille), Dune Drift (1-bit dither), Koi Pond (halftone) and Drift. Each has light and dark versions and Windows Terminal and Ghostty shaders.
- Cell engine with six mark styles. Any theme can be drawn in any style with `--mark`.
- `diorama apply` for VS Code, Cursor, Windsurf and VSCodium, with `restore` undoing every change.
- `diorama launch` for the Codex desktop app and any Electron app that accepts a DevTools port.
- Browser extension for claude.ai and chatgpt.com.
- Editor extension that re-applies the theme after editor updates.
- `diorama preview` demo app and gallery, `diorama new` for your own themes, skins and apps, and `diorama build` for the extensions and the demo site.
